# Andrew Wevell - Digital Marketing Manager CV

This is my professional CV website.

## Files
- `andrewwevellcv.html` - Main HTML file
- `styles.css` - Stylesheet
- `app.js` - JavaScript functionality

## Publishing to GitHub Pages

1. Create a new repository on GitHub (e.g., `andrewwevellcv` or `cv`)
2. Push this code to your repository:
   ```bash
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. Go to your repository settings on GitHub
4. Navigate to "Pages" in the left sidebar
5. Under "Source", select "Deploy from a branch"
6. Choose "main" branch and "/ (root)" folder
7. Click "Save"
8. Your site will be available at: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/andrewwevellcv.html`

## Alternative: Rename to index.html

If you want the site to be accessible at the root URL (without `/andrewwevellcv.html`), you can:
1. Rename `andrewwevellcv.html` to `index.html`
2. Your site will be available at: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
